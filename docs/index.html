Architectural Innovations & Novelty Formulations

How our Hybrid ML-DNN framework solves fundamental spam and phishing bypass methods
Novelty 1 Dynamic Trust Gate

Adaptive Gated Cross-Attention Fusion (AGCAF)

Standard fusion concatenates metadata blindly. AGCAF computes the entropy and consistency of structured headers against textual semantics. If metadata appears forged or spoofed, a dynamic gate $g \in [0, 1]$ downweights the metadata branch to prevent corrupted signals.

g = σ(W_g · [h_text ⊕ h_meta] + b_g)
Novelty 2 Adversarial Defense

Supervised Contrastive Adversarial Regularization (SCAR)

Attackers use character substitution (e.g., p@ssw0rd) to jump decision boundaries. SCAR acts as a topological magnet during training, mapping adversarial perturbed texts directly back to canonical anchor embeddings.

L_total = L_evidential + λ · L_contrastive(z_anchor, z_adv)
Novelty 3 Uncertainty Estimation

Evidential Epistemic Uncertainty Estimation

Replaces overconfident Softmax with a Dirichlet distribution over class probabilities. Outputs an explicit epistemic uncertainty metric ($u$). When encountering previously unseen zero-day attacks, the model flags the threat for SOC review instead of making an overconfident false guess.

u = K / ∑(alpha_k) ∈ [0, 1]
Novelty 4 Threat Intel Memory

Retrieval-Augmented Threat Intelligence (RATI)

Augments the neural latent vector by querying an indexed vector database of real-time zero-day clusters. Generates similarity-modulated features to recognize emerging polymorphic attack vectors instantly.

f_rati = W_r(h_text) × max_sim(h_text, DB_threats)
